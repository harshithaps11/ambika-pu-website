# Using the administration panel

Sign in at **`/admin`**. The panel is not linked from the public navigation;
only people with an account can reach it.

---

## The two kinds of account

**Owner** — the developer/proprietor account. Has every permission on every
campus, always. Only an owner can create staff accounts and decide what they
can do.

**College staff** — accounts for the office. A new staff account starts with
**no permissions at all**. The owner ticks exactly what that person needs, and
can untick any of it later. The change takes effect on the staff member's very
next page load; they do not need to sign out.

The menu on the left only shows sections the account has permission for, so
staff never see a screen they cannot use.

---

## Creating a staff account

1. **Staff Accounts → Add staff account**
2. Enter a name and email. A temporary password is generated and shown **once**
   — write it down and give it to the staff member.
3. Choose campus access: either all campuses, or tick the specific ones.
4. Tick the permissions they need.
5. They are asked to set their own password the first time they sign in.

To change what someone can do later, open their name in **Staff Accounts**,
tick or untick, and save.

## What each permission allows

| Permission | What it allows |
|---|---|
| View news & notices | See every notice, including drafts and expired ones |
| Create, edit & delete news | Publish notices, set expiry dates, choose ticker headlines |
| View applications | Open the admissions list and read submissions |
| Update application status | Move applicants through shortlisted / admitted / rejected, add office notes |
| Export applications | Download the list as a CSV file — **contains personal data; grant with care** |
| Manage courses | Add or edit combinations, intake, eligibility, fees |
| Manage faculty | Add, edit, reorder and remove staff profiles |
| Manage toppers & results | Publish exam toppers with marks and photographs |
| Manage gallery | Create albums and add or remove photographs |
| Edit page content | Change wording on About, Vision & Mission and similar pages |
| Manage chatbot answers | Edit what the website assistant replies |
| View contact enquiries | Read messages from the contact forms |
| Manage campus settings | Edit addresses, phone numbers, principal's message, admission status |
| View activity log | See who changed what and when |

## Everyday tasks

### Publishing a notice

**News & Notices → Add notice.** Choose the campus, or *Institution-wide* to
show it on the main site and both campus sites.

- **Show in the scrolling updates strip** puts the headline in the rolling bar
  at the top of every page. Keep this to four or five at a time — a ticker with
  twenty items scrolls too long to be read.
- **Remove from the website on** makes a notice disappear by itself. Use it for
  anything with a deadline so old notices do not pile up.
- **Pin to the top** keeps an important notice above newer ones.

### Working through admissions

**Admissions** lists every application. Filter by status, campus, or search by
name, reference number, phone or email. Open one to see the full form and set
its status; office notes are internal and never shown to the applicant.

**Download CSV** exports whatever the current filters show.

### Closing admissions for a campus

**Campus Settings → untick "Admissions are open".** The form stays available but
is presented as an enquiry rather than an application.

### Changing wording on a page

**Page Content.** Each block has a key that tells you where it appears — the
table on that screen lists them. Leave a blank line between paragraphs.

### Teaching the assistant a new answer

**Chatbot Answers → Add an answer.** The *matching words* field matters most:
put in the words people actually type, including common misspellings. The
assistant only ever replies with answers from this list — it never makes one
up, so it cannot quote a wrong fee to a parent.

The *times used* column shows which answers people reach. If visitors keep
asking something that has no answer, add one.

## Security notes for the college

- Never share one account between several people. The activity log is only
  useful if each person has their own sign-in.
- When a staff member leaves, open their account and untick **Account is
  active**. That signs them out everywhere immediately.
- Grant **Export applications** only to people who need the spreadsheet.
  Exports contain students' phone numbers and addresses.
